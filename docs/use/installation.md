# Installation

The *flingo* system is available in [PyPI](https://pypi.org/project/flingo/).
Install it using pip by running the following command in your terminal:

```console
pip install flingo
```

-----

A successful installation will make the `flingo` command available in your terminal. You can check the installation by running:

```console
flingo -h
```

This will display the help message with available options and usage instructions, for detailed CLI information refer to the [CLI documentation](../reference/cli/index.md).
